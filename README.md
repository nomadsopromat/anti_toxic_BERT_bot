### Telegram Toxicity Filter Bot (ruBERT + FastAPI)

Асинхронный Телеграм-бот для автоматической модерации чатов и фильтрации токсичного контента. Проект разделен на легковесный клиент бота (aiogram) и производительный микросервис классификации текста (FastAPI), использующий легковесную, но эффективную модель **rubert-tiny-toxicity**. 

### 🏗 Архитектура и стек

Проект спроектирован по принципу разделения интерфейса и бизнес-логики: 

* **Bot Service (aiogram v3):** Мониторит сообщения в чатах, отправляет текст на скоринг через API и удаляет токсичный контент.
* **ML API (FastAPI):** Веб-сервер, который держит модель в памяти и предоставляет REST API эндпоинт для оценки токсичности текста.
* **Machine Learning:** Transformers (Hugging Face), PyTorch, cointegrated/rubert-tiny-toxicity.

### 📌 Ключевые фичи

* **Низкое потребление RAM:** Использование rubert-tiny позволяет запускать API даже на слабых серверах (VPS).
* **Разделение нагрузок:** Сервер обработки текста (FastAPI) изолирован от логики самого бота.
* **Авто-модерация:** Моментальное удаление сообщений, если вероятность токсичности превышает 50%.
* **CI/CD & Configs:** Все конфигурационные файлы, переменные и пайплайны развертывания уже настроены на GitHub.

### 🔌 API Спецификация (FastAPI)

Бот общается с микросервисом классификации с помощью REST API. 

### Проверка статуса API

* **Endpoint:** GET /
* **Ответ:** {"status": "API готово к работе"}

### Проверка текста на токсичность

* **Endpoint:** POST /predict
* **Headers:** Content-Type: application/json

**Пример тела запроса (Request Body):** 

json

{
  "text": "Привет! Отличный проект, спасибо за код."
}


**Пример ответа (Response Body — Чистый текст):** 

json

{
  "text": "Привет! Отличный проект, спасибо за код.",
  "is_toxic": false,
  "probability": 1.25
}


**Пример ответа (Response Body — Токсичный текст):** 

json

{
  "text": "Ты полный идиот, удали этот репозиторий!",
  "is_toxic": true,
  "probability": 98.45
}


### 🛠 Быстрый старт

## 📁 Структура проекта

├── api.py          # Микросервис FastAPI с ИИ-моделью
├── bot.py          # Телеграм-бот на aiogram v3
├── requirements.txt # Зависимости проекта
└── .env            # Переменные окружения (локально)

## 🛠 Быстрый старт

### 1. Клонирование и установка
```bash
git clone https://github.com
cd your-repo-name
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Конфигурация (.env)
Создайте `.env` локально (на GitHub настройки подтягиваются автоматически):
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwXyZ
```

### 3. Запуск (в двух разных терминалах)
```bash
# Терминал 1: запуск ИИ-сервера
python api.py

# Терминал 2: запуск бота
python bot.py
```
